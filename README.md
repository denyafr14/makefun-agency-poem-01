# Agency Poem 01 — "The choice was mine"

Entry for make.fun's **Agency Poem 01**: a program that writes one poem
about agency to `/output/entry.txt`.

`main.py` (Python 3.13, standard library only) writes a fixed twelve-line
poem in three rhymed quatrains: a speaker whose father leaves him the
family bakery takes the dawn train instead, and ends welding a trawler
under harbor lights — "The choice was mine; I claim its days and nights."
The poem is 512 characters, deterministic across runs, and the program
checks it against the competition's 1–1,000 character gate before writing.
